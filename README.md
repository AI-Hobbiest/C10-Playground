# C10-Playground

A growing, mobile-friendly, non-commercial Class 10 CBSE learning portal. Version 1 starts with Science practice; Mathematics, English, Social Science and Hindi/second-language modules are planned.

## Deploy with GitHub Pages

1. In repository **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**.
2. Open **Actions** and select **Deploy C10-Playground to GitHub Pages**.
3. Watch the workflow triggered by commits to `main`. When it succeeds, the home page will be available at `https://AI-Hobbiest.github.io/C10-Playground/`.

The site is a static website. No Python or build step is needed on student devices. The full Science practice module with the embedded question bank is prepared separately and still needs to be committed before the Science card can open the complete module.

This is a non-commercial revision aid. Please verify chapter coverage against the student's current school syllabus. Scores stored by the practice app are local to each browser and do not sync across devices yet.
